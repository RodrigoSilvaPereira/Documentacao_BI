Tive uma ideia para documentação dos meus Dashboards feitos no Power BI.

Essa ideia se trata de um sistema onde vamos cadastrando informações dos BIs. Conforme as informações são preenchidas, o sistema vai montando automaticamente uma documentação completa do projeto. Por exemplo, eu apenas cadastro os dados e ele gera um README totalmente estruturado para mim.

Segue as ideias principais que eu tive:

Ele vai ter 7 seções, percorrendo uma de cada vez, em ordem:

Projeto > KPIs > Queries > Relacionamentos > Medidas DAX > Páginas > Exportar

Cada seção será responsável por cadastrar os dados, e a função Exportar será responsável por gerar a documentação final.

Pronto! A ferramenta está completa.

Veja o que você tem disponível em cada aba:

Projeto — nome, área, responsável, datas, objetivo, fontes de dados e informações gerais do relatório.

KPIs — para cada KPI você documenta o que mede, o objetivo, as regras de negócio e observações importantes.

Queries — tabela/query, fonte de dados, código SQL ou M, transformações do Power Query e colunas principais.

Relacionamentos — origem, destino, colunas, cardinalidade, direção do filtro e status do relacionamento.

Medidas DAX — nome, tabela, descrição, fórmula completa, dependências, KPIs relacionados e comportamentos esperados.

Páginas — documentação completa da camada visual do dashboard, incluindo páginas, visuais, indicadores, filtros, tabelas utilizadas, medidas utilizadas e capturas de tela.

Exportar — gera toda a documentação do projeto em diferentes formatos.

Você pode adicionar quantos KPIs, Queries, Relacionamentos, Medidas DAX, Páginas, Visuais e Filtros desejar antes de exportar.

BI Documentation Studio - V1
Objetivo

Criar uma aplicação desktop para documentação de projetos Power BI, permitindo cadastrar informações estruturadas sobre relatórios, KPIs, queries, relacionamentos, medidas DAX e páginas do relatório, gerando automaticamente documentação em Markdown e mantendo um histórico de versões.
