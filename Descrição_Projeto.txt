Tive uma ideia para documentação dos meus Dashboards feito no powerBI

Essa ideia se trata de um sistema, onde vamos cadastrando informações dos BIs, ele vai completano um README pra mim por exemplo, eu só coloco as informações, e ele gera o README montado pra mim.

Segue as ideias principais que eu tive:

Ele vai ter 6 seções, percorrendo uma de cada vez, em ordem:

Projeto > KPIs > Medidas DAX > Queries > Relacionamentos > Exportar

Cada seção será responsável por cadastrar os dados, e a função exportar, vai gerar o README final bem montado.
