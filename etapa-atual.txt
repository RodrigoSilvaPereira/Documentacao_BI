Tive uma ideia para documentação dos meus Dashboards feitos no Power BI.

Essa ideia se trata de um sistema onde vamos cadastrando informações dos BIs. Conforme as informações são preenchidas, o sistema vai montando automaticamente uma documentação completa do projeto. Por exemplo, eu apenas cadastro os dados e ele gera um README totalmente estruturado para mim.

Segue as ideias principais que eu tive:

Ele vai ter 7 seções, percorrendo uma de cada vez, em ordem:

Projeto > KPIs > Queries > Relacionamentos > Medidas DAX > Páginas > Exportar

Cada seção será responsável por cadastrar os dados, e a função Exportar será responsável por gerar a documentação final.
