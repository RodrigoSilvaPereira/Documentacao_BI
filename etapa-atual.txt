Criando o projeto
1. Criar projeto React + TypeScript
npm create vite@latest bi-documentation-studio -- --template react-ts

Entrar na pasta:

cd bi-documentation-studio
2. Instalar dependências principais
npm install
3. Adicionar Tauri v2
npm install @tauri-apps/api
npm install -D @tauri-apps/cli

Inicializar:

npx tauri init

Escolha:

Frontend: Vite
Dev Command: npm run dev
Build Command: npm run build
Dist Folder: ../dist
4. Instalar Tailwind
npm install tailwindcss @tailwindcss/vite
5. Instalar Zustand
npm install zustand immer
6. Instalar React Router
npm install react-router-dom
7. Instalar utilitários
npm install date-fns
npm install lucide-react
npm install clsx
npm install uuid
8. Instalar Radix UI

Inicialmente:

npm install @radix-ui/react-dialog
npm install @radix-ui/react-select
npm install @radix-ui/react-tooltip

Depois adicionamos os demais.

BI Documentation Studio — Status Atual do Desenvolvimento
Objetivo do Sistema

Criar uma aplicação desktop para documentar projetos Power BI de forma estruturada.

A documentação será cadastrada através de formulários e armazenada em:

documentacao.json

A partir desse JSON, o sistema será capaz de gerar:

README.md

e manter um histórico de exportações.
